# CYBERSEC 2026 Slide Output Practice Capture

Date: `2026-04-27`

Purpose: capture fast slide-by-slide spoken drafts from Notion and convert them into a speakable rehearsal script plus a small repair list.

This is an output-practice workspace. It is not a new knowledge-reading note and not a replacement for the canonical deck PDF.

## Practice Rule

From `13:30`, the useful work is:

1. Write how each slide would actually be spoken.
2. Preserve unclear logic, imprecise claims, awkward transitions, and待查 notes.
3. Turn each weak point into one bounded repair.
4. Avoid opening a broad research sprint unless a slide cannot be made public-safe or technically accurate without a source check.

## Routing

- Planning repo owns time, priority, capacity, and status.
- This talk repo owns the reusable spoken draft, slide weakness list, and repair decisions.
- Notion is the fast capture surface; this file is the durable repo capture after paste-back.

## Paste-Back Template

Use this structure when rough Notion text is pasted back.

```text
Slide:
Current spoken draft:
What feels unclear:
What might be technically imprecise:
Need to check:
Repair decision:
Keep / cut / rewrite:
```

## Readiness Signal

The output-practice pass is useful when:

- Each non-disclaimer slide has at least one speakable spoken draft.
- The weak points are visible instead of hidden.
-待查 items are few and specific.
- The next timed run has cut markers instead of more background reading.
